HOW TO USE

B50 Pocket 설명서

처음 B50을 한 번 가져온 뒤에는 평소 기갱한 기록만 추가하면 돼. 곡 데이터와 자켓은 자동으로 최신 정보를 확인해.

01

처음 시작할 때

Arcaea Online의 B50 전체 이미지를 준비하고, ‘기록 입력 → 이미지로 기록 등록’에서 올려. AI가 50칸의 곡명·점수·성과·난이도를 읽고 곡 DB와 맞춰줘.

이미지 인식은 주로 최초 세팅용이야. 결과를 한 번 확인해서 잘못 읽은 점수나 보면이 없는지 보고 등록하면 돼. 필요하면 나중에도 다시 사용할 수 있어.
02

그다음부터는 기록만 갱신

새 기록이 생기면 ‘기록 입력’에서 곡 검색 → 보면 선택 → 점수 입력 → 저장하면 돼. 같은 보면의 더 좋은 기록을 넣으면 B50 계산에 새 기록이 반영돼.

03

B50 화면

저장된 기록을 곡의 세부난이도(CC)와 점수로 계산해서 성과가 높은 50개를 보여줘. 위의 ‘50위’는 현재 B50 커트라인이야.

04

곡 추천

빠른 기갱내가 이미 플레이한 B50 기록 중 적은 점수 상승으로 올리기 좋은 곡을 찾음.
하위권 재도전B50 하위권이나 저장된 비B50 기록 중 다시 치면 순위를 올리기 좋은 곡을 찾음.
고난도 재도전이미 플레이한 고난도 곡 중 점수 여지가 큰 기록을 다시 추천.
자동 계산추천은 미플레이 곡을 추측하지 않고 저장된 실제 기록과 CC만 기준으로 계산함.
05

곡·자켓 업데이트

곡/세부난이도 DB와 자켓 목록은 웹을 사용할 때 자동으로 최신 데이터를 확인해. 신곡이 나온 뒤 외부 데이터 소스가 갱신되면 이 웹에도 따라 들어와.

상단의 ↻ 버튼을 누르면 곡 데이터와 자켓을 강제로 다시 확인할 수 있어. 업데이트 직후에는 외부 DB 반영까지 약간의 시간이 걸릴 수 있음.
06

저장·백업·이미지

닉네임과 기록은 현재 브라우저의 저장소에 보관돼. 이미지 분석용 캡처는 분석 과정에 사용되고 기록 이미지 자체를 저장하지 않아.

브라우저 데이터 삭제나 기기 변경 시 기록이 사라질 수 있으니, 설정의 ‘백업 파일 내보내기’를 가끔 해두는 걸 권장해.
이 웹은 비공식 Arcaea 기록 관리 도구야. AI 이미지 인식은 편의를 위한 기능이라 드물게 숫자나 보면을 잘못 읽을 수 있으니 최초 등록 때 결과를 한 번 확인하는 게 좋아.
